## Structs

### SpokeSnapshotContext

Spoke caliber accounting snapshot context.

```solidity
struct SpokeSnapshotContext {
        uint256 chainId;
        address mailbox;
        uint256 blockNum;
        uint256 blockTime;
    }
```

**Properties**

| Name      | Type      | Description                                               |
| --------- | --------- | --------------------------------------------------------- |
| chainId   | `uint256` | The chain ID of the spoke caliber.                        |
| mailbox   | `address` | The address of the spoke caliber mailbox.                 |
| blockNum  | `uint256` | The block number used as the snapshot reference point.    |
| blockTime | `uint256` | The block timestamp used as the snapshot reference point. |

### SpokeCaliberAccountingData

Spoke caliber accounting snapshot data.

```solidity
struct SpokeCaliberAccountingData {
        uint256 netAum;
        bytes[] bridgesIn;
        bytes[] bridgesOut;
        SpokeSnapshotContext context;
    }
```

**Properties**

| Name       | Type                   | Description                                                                     |
| ---------- | ---------------------- | ------------------------------------------------------------------------------- |
| netAum     | `uint256`              | The net AUM denominated in the caliber accounting token.                        |
| bridgesIn  | `bytes[]`              | The list of incoming bridge amounts, each encoded as abi.encode(token, amount). |
| bridgesOut | `bytes[]`              | The list of outgoing bridge amounts, each encoded as abi.encode(token, amount). |
| context    | `SpokeSnapshotContext` | The snapshot context.                                                           |
