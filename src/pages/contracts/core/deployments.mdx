# Deployments

Makina runs as **instances**: a hub chain that hosts Machines, plus the spoke chains its Calibers can expand to. Each instance has its own core registry, factory, beacons and swap module. Chain-scoped infrastructure (AccessManager, OracleRegistry, TokenRegistry and the bridge configs) is deployed once per chain and shared by every instance present on that chain.

:::info

For strategy-specific contracts, see the [Strategies](../../strategies/deployments) page.

:::
