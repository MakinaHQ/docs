<a id="lzcompose-address-bytes32-bytes-address-bytes"></a>

### lzCompose

Composes a LayerZero message from an OApp.

```solidity
function lzCompose(
        address _from,
        bytes32, /*_guid*/
        bytes calldata _message,
        address, /*_executor*/
        bytes calldata /*_extraData*/
    )
        external
        payable
        override;
```

**Parameters**

| Name      | Type      | Description                                                                                   |
| --------- | --------- | --------------------------------------------------------------------------------------------- |
| \_from    | `address` | The address initiating the composition, typically the OApp where the lzReceive was called.    |
| \_        | `bytes32` | The unique identifier for the corresponding LayerZero src/dst tx.                             |
| \_message | `bytes`   | The composed message payload in bytes. NOT necessarily the same payload passed via lzReceive. |
| \_        | `address` | The address of the executor for the composed message.                                         |
| \_        | `bytes`   | Additional arbitrary data in bytes passed by the entity who executes the lzCompose.           |
