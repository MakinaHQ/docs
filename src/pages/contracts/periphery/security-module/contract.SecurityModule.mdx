<a id="startcooldown-uint256-address"></a>

### startCooldown

Requests a cooldown for redeeming security shares.
Shares are locked in the contract until the cooldown is cancelled or expires.
A cooldown receipt NFT is minted to the specified receiver address.

```solidity
function startCooldown(uint256 shares, address receiver)
        external
        override
        nonReentrant
        returns (uint256, uint256, uint256);
```

**Parameters**

| Name     | Type      | Description                                         |
| -------- | --------- | --------------------------------------------------- |
| shares   | `uint256` | The amount of security shares to redeem.            |
| receiver | `address` | The address that will receive the cooldown receipt. |

**Returns**

| Name         | Type      | Description                                                                         |
| ------------ | --------- | ----------------------------------------------------------------------------------- |
| &lt;none&gt; | `uint256` | The ID of the minted cooldown receipt NFT representing the pending cooldown.        |
| &lt;none&gt; | `uint256` | The maximum amount of machine shares that can be redeemed.                          |
| &lt;none&gt; | `uint256` | The timestamp at which the cooldown period will end and the shares can be redeemed. |

<a id="cancelcooldown-uint256"></a>

### cancelCooldown

Cancels a pending cooldown.


| Name         | Type      | Description                                                         |
| ------------ | --------- | ------------------------------------------------------------------- |
| &lt;none&gt; | `uint256` | The amount of security shares for which the cooldown was cancelled. |
