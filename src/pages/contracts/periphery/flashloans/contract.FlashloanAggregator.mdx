<a id="receiveflashloan-balancerierc20-uint256-uint256-bytes"></a>

### receiveFlashLoan

<i>

When `flashLoan` is called on the Vault, it invokes the `receiveFlashLoan` hook on the recipient.

At the time of the call, the Vault will have transferred `amounts` for `tokens` to the recipient. Before this
call returns, the recipient must have transferred `amounts` plus `feeAmounts` for each token back to the
Vault, or else the entire flash loan will revert.

`userData` is the same value passed in the `IVault.flashLoan` call.

</i>

```solidity
function receiveFlashLoan(
        BalancerIERC20[] memory tokens,
        uint256[] memory amounts,
        uint256[] memory feeAmounts,
        bytes memory userData
    ) external override;
```

**Parameters**

| Name       | Type               | Description |
| ---------- | ------------------ | ----------- |
| tokens     | `BalancerIERC20[]` |             |
| amounts    | `uint256[]`        |             |
| feeAmounts | `uint256[]`        |             |
| userData   | `bytes`            |             |
