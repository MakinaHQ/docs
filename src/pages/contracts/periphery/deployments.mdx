# Deployments

Periphery contracts follow the same instance structure as the [core contracts](../core/deployments): each hub chain hosts a periphery registry, factory and beacons, and every chain of an instance hosts a FlashloanAggregator bound to that instance. The stateless Weiroll helpers are shared by every instance on a chain.

:::info

For strategy-specific contracts, see the [Strategies](../../strategies/deployments) page.

:::
